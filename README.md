# VolleyFlow Planner

A small volleyball tournament setup app for balancing teams, generating a round robin schedule, and advancing to semifinals and a final.

Tiny update for the repo.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

This repo is set up to deploy from GitHub Actions to the `https://arvingraff.github.io/volleyball/` Pages URL.

1. Push the `main` branch to GitHub.
2. In the GitHub repo, go to `Settings` > `Pages`.
3. Set the source to `GitHub Actions`.
4. Push any change to `main` and GitHub will build and publish the site automatically.
